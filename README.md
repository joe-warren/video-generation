# video-generation

Experiments in programatically generating faux live-coding video with Haskell.

Uses [Waterfall-CAD](https://hackage.haskell.org/package/waterfall-cad) for 3D object design, and [Tidal-Cycles](https://tidalcycles.org/) for the soundtrack.

* [The Hook Video (youtube)](https://www.youtube.com/R_ir7E8EDcAgA)
